# Frontend i18n with next-intl Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Extract every user-facing frontend string into `en`/`ru` next-intl catalogs, store the locale in an `NEXT_LOCALE` cookie (default English), and add a switcher that retranslates the current screen without changing URLs or restarting the Godot iframe.

**Architecture:** next-intl without locale routing. `src/i18n/request.ts` reads the cookie on the server; the async root layout sets `<html lang>` and wraps the app in `NextIntlClientProvider`. Components use `useTranslations`; long-lived state (`GameTab`, `use-room-packages`) stores `AppMessage` keys plus values and translates at render time. A small client `LocaleSwitcher` writes the cookie and calls `router.refresh()`.

**Tech Stack:** Next.js 16.0.7 App Router (webpack), React 19.2.0, TypeScript strict, next-intl ^4.14.9, Vitest 5 + Testing Library + jsdom, pnpm workspace.

**Spec:** `docs/superpowers/specs/2026-11-03-frontend-i18n-design.md`

## Global Constraints

- Locales are exactly `["en", "ru"]`; `en` is the default. Cookie name is exactly `NEXT_LOCALE` (`path=/; max-age=31536000; samesite=lax`, plus `secure` on https).
- No `[locale]` URL segment, no middleware, no `Accept-Language` negotiation, no User/DB/server changes.
- URLs, especially `/room/<hashid>`, must not change. A language switch must not navigate or remount the game iframe.
- Existing Russian copy is frozen byte-for-byte, including typos (`предлагаю присоединица`). English-origin copy keeps its current text in `en.json`; `ru.json` is a by-meaning translation.
- External text stays verbatim: Godot payload `message`/`detail`, `entry.runtimeError`, engine failure text. It is the only raw text allowed in the UI.
- Our own errors never render `Error.message` or a Nest message. They render an `AppMessage`; the original goes to `console.error`.
- State that outlives a render stores `AppMessage` (`{ key, values }`), never a translated string.
- Tests render translated components through `src/test/render-with-intl.tsx` with `locale: "ru"` by default.
- Only new dependency: `next-intl@^4.14.9`. Keep `--webpack`; do not add Turbopack.
- Run commands from the repository root. Every task ends with `pnpm --filter frontend exec vitest run <files>` passing and a conventional commit.

## Review Focus

1. A missing, invalid, or tampered `NEXT_LOCALE` cookie must render English and must not throw; pinned by `resolveLocale` tests in Task 1.
2. Switching language while a game status is already on screen must retranslate that status and keep the same iframe element; pinned by the provider-rerender test in Task 3.
3. An API/network failure with no HTTP status (offline, DNS, non-axios throw) must show `Errors.unexpected`, never the raw English message; pinned by `toAppMessage` and `useRequestHandler` tests in Task 2.
4. A missing `ru` key or a mismatched ICU placeholder must fail the catalog parity test instead of producing a runtime error; pinned in Task 1.
5. A Godot payload with an empty/undefined `message` or `detail` must fall back to the translated `Game.error`, and markup in the payload must render as text; pinned in Task 3.

import en from "../../messages/en.json";

type Json = { [key: string]: string | Json };

function keyPaths(value: Json, prefix = ""): string[] {
  return Object.entries(value).flatMap(([key, child]) =>
    typeof child === "string"
      ? [`${prefix}${key}`]
      : keyPaths(child, `${prefix}${key}.`),
  ).sort();
}

function icuVariables(message: string): string[] {
  return [...message.matchAll(/\{(\w+)[,}]/g)].map((match) => match[1]).sort();
}

describe("message catalogs", () => {
  it("have the same keys", () => {
    expect(keyPaths(ru as Json)).toEqual(keyPaths(en as Json));
  });

  it("use the same ICU variables for every key", () => {
    const paths = keyPaths(en as Json);
    for (const path of paths) {
      const lookup = (catalog: Json) =>
        path.split(".").reduce<string | Json>((node, part) => (node as Json)[part], catalog) as string;
      expect(icuVariables(lookup(ru as Json)), path).toEqual(
        icuVariables(lookup(en as Json)),
      );
    }
  });
});

```ts
import { useTranslations } from "next-intl";
import { useCallback } from "react";
import type en from "../../messages/en.json";

type NestedKeyOf<T> = {
  [K in keyof T & string]: T[K] extends string
    ? K
    : `${K}.${NestedKeyOf<T[K]>}`;
}[keyof T & string];

export type MessageKey = NestedKeyOf<typeof en>;
export type AppMessage = {
  key: MessageKey;
  values?: Record<string, string | number>;
};

export function useAppMessage() {
  const t = useTranslations();
  return useCallback(
    (message: AppMessage) => t(message.key, message.values),
    [t],
  );
}
```

If TypeScript rejects the root `t(message.key, ...)` overload, cast once inside this function (`t(message.key as never, message.values as never)`) and leave all call sites typed.

`frontend/src/components/i18n/LocaleSwitcher.tsx`:

```tsx
"use client";

import { useLocale, useTranslations } from "next-intl";
import { useRouter } from "next/navigation";
import { useTransition } from "react";
import { LOCALE_COOKIE, locales, type Locale } from "@/i18n/config";

const LABELS: Record<Locale, string> = { en: "English", ru: "Русский" };

export function LocaleSwitcher({ className = "" }: { className?: string }) {
  const locale = useLocale() as Locale;
  const t = useTranslations("Common");
  const router = useRouter();
  const [pending, startTransition] = useTransition();

  function switchTo(next: Locale) {
    if (next === locale) return;
    const secure = window.location.protocol === "https:" ? "; secure" : "";
    document.cookie = `${LOCALE_COOKIE}=${next}; path=/; max-age=31536000; samesite=lax${secure}`;
    startTransition(() => router.refresh());
  }

  return (
    <div
      role="group"
      aria-label={t("language")}
      className={`flex items-center gap-1 rounded-md border border-white/20 bg-black/40 p-1 text-xs ${className}`}
    >
      {locales.map((value) => (
        <button
          key={value}
          type="button"
          aria-pressed={value === locale}
          disabled={pending}
          onClick={() => switchTo(value)}
          className={
            value === locale
              ? "rounded px-2 py-1 text-white"
              : "rounded px-2 py-1 text-white/60 hover:text-white"
          }
        >
          {LABELS[value]}
        </button>
      ))}
    </div>
  );
}
```

`frontend/src/i18n/api-error.ts`:

```ts
import { isAxiosError } from "axios";
import type { AppMessage } from "./message";

export function toAppMessage(error: unknown): AppMessage {
  const status = isAxiosError(error) ? error.response?.status : undefined;
  if (status === 401) return { key: "Errors.unauthorized" };
  if (status === 403) return { key: "Errors.forbidden" };
  if (status === 404) return { key: "Errors.notFound" };
  if (status === 409) return { key: "Errors.conflict" };
  if (status !== undefined && status >= 500) return { key: "Errors.server" };
  console.error(error);
  return { key: "Errors.unexpected" };
}
```
