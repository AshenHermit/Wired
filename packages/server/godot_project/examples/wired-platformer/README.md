# Пример пакета: Wired Platformer

Готовый пример пакета комнаты: платформа, игрок с камерой и толканием, спавн
ящиков по ЛКМ и динамические ящики с сохранением.

Исходники лежат **вне** базового проекта `packages/server/godot_project/_wired`,
поэтому не попадают автоматически в редактор каждой комнаты. Пакет публикуется
в конкретную комнату через вкладку **Packages**.

## Состав

```
wired-platformer/
  wired_package.gd          # точка входа пакета, пять регистраций
  static/platform.tscn      # StaticBody2D 640×32 + маркер спавна
  player/body.tscn          # CharacterBody2D, движение, прыжок, толкание
  player/camera.tscn        # Camera2D, следует только за своим игроком
  player/spawner.tscn       # ЛКМ → запрос на спавн ящика
  dynamic/crate.tscn        # RigidBody2D, импульс, сохранение состояния
```

`wired_package.gd` регистрирует:

| Что | Путь | order | authority | Примечание |
|---|---|---|---|---|
| статика | `static/platform.tscn` | 10 | server | платформа и маркер `wired_player_spawn` |
| игрок | `player/body.tscn` | 10 | server | движение, прыжок, толкание |
| игрок | `player/camera.tscn` | 20 | local | `local_only`, камера только у своего игрока |
| игрок | `player/spawner.tscn` | 30 | server | обработка запроса на ящик |
| динамика | `dynamic/crate.tscn` | — | server | тип `crate`, `persist`, лимит 8 на игрока |

Все пути относительны корня пакета, поэтому каталог можно копировать в
`res://packages/<id>` без правок. Скрипты примера не объявляют `class_name` и не
используют RPC: вся сетевая логика идёт через ядро `_wired`.

## Как опубликовать пакет в комнате

Для ручной проверки нужны собранный Web export (`pnpm export:game`), запущенные
backend и frontend и открытая комната.

1. Откройте вкладку **Packages** (панель «Пакеты комнаты»).
2. Создайте пакет: укажите «Имя пакета» (например, `Wired Platformer`) и
   «Версию» (например, `0.1.0`), нажмите **Создать пакет**. В карточке пакета
   появится его id — `#<id>`; в редакторе появится пустой каталог
   `packages/<id>`.
3. Скопируйте содержимое
   `packages/server/godot_project/examples/wired-platformer/` в
   `packages/<id>/` в файловой системе редактора (вкладка **FileSystem**),
   сохранив структуру каталогов: `wired_package.gd`, `static/`, `player/`,
   `dynamic/`.
   - Если пакет уже публиковался, сначала нажмите **Скачать в редактор**, затем
     замените файлы примером. Кнопка **Убрать из редактора** удаляет только
     каталог этого пакета.
4. Нажмите **Emit** в карточке пакета. Панель покажет опубликованную ревизию;
   runtime комнаты применит её и разошлёт клиентам.
5. Откройте вкладку **Game** в двух окнах или вкладках браузера (два клиента
   одной комнаты). Первый запуск runtime и синхронизация пакетов занимают
   несколько секунд.

Первый клиент запускает серверный runtime комнаты; второй подключается к нему.
Если игроки уже были в игре во время Emit, статика применится сразу, а для
компонентов игрока (тело, камера, спавнер) нужен reconnect/повторный вход.

## Управление

| Действие | Клавиши |
|---|---|
| движение | A / D или ← / → |
| вверх / вниз | W / S или ↑ / ↓ |
| прыжок | Space |
| спавн ящика | ЛКМ |

## Что должно работать

- Платформа 640×32 видна обоим клиентам; сцена содержит `Marker2D` `Spawn`
  в группе `wired_player_spawn`.
- У каждого клиента свой игрок, камера следует только за своим и не
  перехватывает вид у второго.
- Движение и прыжок реплицируются: второй клиент видит те же перемещения.
- Игроки толкают друг друга, толчок не телепортирует тело и плавно затухает.
- ЛКМ спавнит ящик рядом с игроком в сторону курсора; импульс и полёт видны
  обоим клиентам.
- Ящик сталкивается с платформой и игроками, лимит — 8 живых ящиков на игрока,
  кулдаун — 250 мс.
- Ящики сохраняются в `state.json` и восстанавливаются после перезапуска
  runtime комнаты (импульс при восстановлении не повторяется).

## Если что-то не работает

- **Emit недоступен.** Пакет не загружен в редактор: нажмите **Скачать в
  редактор** (для нового пустого пакета каталог создаётся сразу).
- **Каталога `packages/<id>` не видно во вкладке FileSystem.** Сохраните сцены и
  выполните Project → Reload Current Project. Перезагрузка страницы сбрасывает
  набор загруженных пакетов.
- **Вкладка Game сообщает об отсутствии сборки.** Соберите Web export командой
  `pnpm export:game` и обновите страницу.
- **Ящики не спавнятся.** Проверьте лимит 8 на игрока и кулдаун 250 мс; запрос
  принимается только от локального игрока.
- **После Emit пропали камера или управление.** Переподключитесь к комнате:
  компоненты игрока собираются при спавне, а не на лету.
