# Wired frontend

Next.js App Router frontend for Wired. `AGENTS.md` at the repository root is the
only maintained map of the repo: it lists the route groups, the conventions this
codebase follows, the dev commands (the frontend runs on port 3001, because the
API owns 3000) and the deployment model (Docker + nginx, not Vercel).

Component naming and file placement rules for this package live in
[docs/frontend-conventions.md](../docs/frontend-conventions.md).
