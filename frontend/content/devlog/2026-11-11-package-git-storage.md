---
title: Ревизии пакетов в git-хранилище
date: 2026-11-11
summary: Каждая ревизия пакета — коммит в отдельном bare-репозитории, чтение идёт по `commitSha`
version: 0.4.0
---

Ревизия пакета теперь — это коммит в отдельном bare-репозитории пакета, а не каталог с файлами. Публикация записывает блобы, собирает дерево, создаёт коммит и одной транзакцией двигает теги ревизий и `main`. В базе хранится `commitSha`, и содержимое читается по нему.

Клиент этого хеша не видит: сервер сам достаёт файлы через `cat-file` по коммиту из записи ревизии, поэтому запросить произвольный объект хранилища нельзя.

Старые каталоги `revisions/<n>` продолжают читаться, пока их не перенесут в историю git. Хранилище включается переменной `WIRED_PACKAGE_GIT_STORAGE=1`.
